# Checklist antes da avaliação

- [ ] Explicar com minhas palavras o que é o algoritmo de Dijkstra.
- [ ] Identificar vértices, arestas e pesos em um grafo.
- [ ] Explicar por que a origem começa com distância zero.
- [ ] Explicar por que os demais vértices começam com infinito.
- [ ] Identificar o vértice com menor distância provisória.
- [ ] Realizar o relaxamento das arestas.
- [ ] Atualizar corretamente uma tabela de distâncias.
- [ ] Identificar os predecessores dos vértices.
- [ ] Encontrar o caminho mínimo entre dois vértices.
- [ ] Explicar por que Dijkstra não trabalha corretamente com pesos negativos.
- [ ] Desenhar um grafo com pelo menos cinco vértices.
- [ ] Executar manualmente todas as etapas do algoritmo.

### Para revisar:
* Altere pesos ou escolha outra origem e repita a execução.
* Explique em voz alta por que cada atualização aconteceu.
